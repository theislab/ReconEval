Train
~~~~~

:doc:`Back to Foundation model <../foundation_model>`

To explore a demo using the LuCA dataset, see the
:doc:`Foundation-model tutorial <../../tutorials/fm>`.

Configure
^^^^^^^^^

**Data**

See the :ref:`decoder training inputs <custom-data-fm-decoder-training-inputs>`.

**Model**

Train an **MLP decoder** to reconstruct expression from precomputed
:doc:`embeddings <extract_embeddings>` generated by one of the following
foundation models:

- **SE** :cite:p:`adduri:25`
- **scGPT** :cite:p:`cui:24scgpt`
- **scConcept** :cite:p:`bahrami:25`
- **SCimilarity** :cite:p:`heimberg:25`

**Parameters**

Pass these data parameters to ``train_decoder_from_embedding.py`` as CLI flags: ``--flag value``.
No YAML configuration is needed.

Run
^^^

Activate ``reconeval`` using ``cstm_scvi_env.yaml`` from the
:ref:`installation step <custom-data-installation>` and run from the
repository root. For cluster submission, follow
:ref:`Run through Slurm <slurm-parameters>`.

Replace ``<model>`` and ``<embedding_key>`` with ``SE``, ``scGPT``,
``scConcept``, or lowercase ``scimilarity``:

.. code-block:: bash

   python experiments/02_foundation_model/codes/train_decoder_from_embedding.py \
     --emb-train-zarr "/path/to/mydata/embeddings/<model>/train.zarr" \
     --emb-val-zarr "/path/to/mydata/embeddings/<model>/val.zarr" \
     --all-genes-zarr /path/to/mydata/all_genes.zarr \
     --target-genes-zarr /path/to/mydata/target_genes.zarr \
     --embedding-key "<embedding_key>" \
     --out "/path/to/results/mydata/<model>/MLP"

.. _custom-data-fm-decoder-training-outputs:

Outputs
^^^^^^^

**Model files**

Training saves ``.ckpt`` files in the directory specified by ``--out``, e.g.:

.. code-block:: text

   /path/to/results/mydata/<model>/MLP/

**Configuration**

The directory specified by ``--out`` contains a ``config.yaml`` file with the training settings.
