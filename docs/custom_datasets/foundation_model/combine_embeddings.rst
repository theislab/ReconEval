Combine expression and embeddings
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

:doc:`Back to Foundation model <../foundation_model>`

Prepare training and validation stores for the MLP decoder.

Configure
^^^^^^^^^

**Data**

Use the grouped embeddings generated by :doc:`Extract embeddings <extract_embeddings>`,
together with matching grouped expression and split metadata. Matching expression
and embedding groups must contain the same cells in the same row order.

**Parameters**

Pass parameters as CLI flags: ``--flag value``. No YAML configuration is needed.

.. dropdown:: Table: Combination parameters
   :icon: table
   :color: primary

   .. csv-table::
      :header: "Parameter", "Required / optional", "Value / meaning"
      :widths: 35, 25, 40

      "``--expression-zarr``", "Required", "Grouped expression store containing ``<group>/X``"
      "``--split-meta-zarr``", "Required", "Split metadata with ``train_combinations`` and ``val_combinations``"
      "``--embedding-zarr``", "Required", "Grouped embedding store containing ``<group>/X``"
      "``--embedding-key``", "Required", "Embedding key in the output stores, e.g. ``SE``"
      "``--out-dir``", "Required", "Directory for ``train.zarr`` and ``val.zarr``"
      "``--chunk-size``", "Optional; default: ``5000``", "Rows per output Zarr chunk"

Run
^^^

Activate ``reconeval`` using the :ref:`installation instructions <custom-data-installation>`
and run from the repository root, or follow :ref:`Run through Slurm <slurm-parameters>`.

Replace ``<model>`` with ``SE``, ``scGPT``, ``scConcept``, or ``scimilarity``:

.. code-block:: bash

   python experiments/preprocessing/combine_emb_zarr.py \
       --expression-zarr /path/to/mydata/expression_for_fm.zarr \
       --split-meta-zarr /path/to/mydata/split_metadata.zarr \
       --embedding-zarr "/path/to/mydata/embeddings/<model>/grouped.zarr" \
       --embedding-key "<model>" \
       --out-dir "/path/to/mydata/embeddings/<model>"

Outputs
^^^^^^^

``train.zarr`` and ``val.zarr`` are saved under ``--out-dir``. Each contains
expression in ``X`` and embeddings in ``<model>``, as shown in the
:ref:`decoder training inputs <custom-data-fm-decoder-training-inputs>`.

:doc:`Evaluation <evaluate>` reads test groups from grouped stores, so a combined
``test.zarr`` is not needed.
