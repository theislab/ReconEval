STATE and CellFlow environments
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Use one dedicated ``reconeval-state`` environment for both **STATE**
perturbation-model training and **SE** embedding extraction. Use
``reconeval-pancellflow`` for **CellFlow**.
